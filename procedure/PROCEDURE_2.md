# Week 2 procedure — token and grid validation

1. Store the invented token `ORBIT-07` and grid label `GRID-A`.
2. Validate the token’s fixed text pattern.
3. Validate the grid label against the fixed exercise value.
4. Print the ready state.

Compile and run with `javac ParkingWeek02.java` followed by `java ParkingWeek02`.

> This is a fictional classroom slot-allocation simulator. It has no real vehicles, licence plates, people, locations, payments, personal data, or live parking function.
