# Week 4 procedure — scripted grid workflow

1. Print the three illustrative simulator commands.
2. Store three fixed action labels.
3. Use a `while` loop to process all labels.
4. Print the allocation and release actions followed by completion.

Compile and run with `javac ParkingWeek04.java` followed by `java ParkingWeek04`.

> This is a fictional classroom slot-allocation simulator. It has no real vehicles, licence plates, people, locations, payments, personal data, or live parking function.
