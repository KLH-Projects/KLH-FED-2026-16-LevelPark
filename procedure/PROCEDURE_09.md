# Week 9 procedure — training-token, grid-cell, and allocation objects

1. Define small classes for an invented training token, grid cell, and allocation.
2. Create the fixed NOVA-12 / B-01 active allocation.
3. Print the allocation’s object representation and cell status.

Compile and run with `javac ParkingWeek09.java` followed by `java ParkingWeek09`.

> This is a fictional classroom slot-allocation simulator. It has no real vehicles, licence plates, people, locations, payments, personal data, or live parking function.
