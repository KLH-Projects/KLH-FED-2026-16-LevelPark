# Week 11 procedure — synthetic allocation CSV

1. Build a header plus two invented token/cell records.
2. Save them as `simulator-state.csv`.
3. Reload the file and count records after its header.
4. Print the first data row.

Compile and run with `javac ParkingWeek11.java` followed by `java ParkingWeek11`.

> The CSV contains invented training tokens and grid cells only. It is not a real parking, vehicle, payment, location, or identity record.
