# Week 5 procedure — reusable grid methods

1. Write an `allocate` method that returns a fixed success result.
2. Write a `release` method that returns a fixed success result.
3. Update the fictional free-slot count after each successful action.
4. Print the count using the provided method-style label.

Compile and run with `javac ParkingWeek05.java` followed by `java ParkingWeek05`.

> This is a fictional classroom slot-allocation simulator. It has no real vehicles, licence plates, people, locations, payments, personal data, or live parking function.
