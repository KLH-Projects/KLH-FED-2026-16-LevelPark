# Week 10 procedure — simulator command exceptions

1. Validate one supported fixed allocation command.
2. Reject an unknown grid label with a custom exception.
3. Reject a blank token with the same exception type.
4. Catch and print the resulting messages.

Compile and run with `javac ParkingWeek10.java` followed by `java ParkingWeek10`.

> This is a fictional classroom slot-allocation simulator. It has no real vehicles, licence plates, people, locations, payments, personal data, or live parking function.
