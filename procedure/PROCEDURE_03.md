# Week 3 procedure — classroom cell decision

1. Declare one fixed token, cell, and six-slot grid.
2. Use a boolean condition to model the cell’s classroom availability.
3. Decrement the count only when the test is true.
4. Print the request, decision, and remaining count.

Compile and run with `javac ParkingWeek03.java` followed by `java ParkingWeek03`.

> This is a fictional classroom slot-allocation simulator. It has no real vehicles, licence plates, people, locations, payments, personal data, or live parking function.
