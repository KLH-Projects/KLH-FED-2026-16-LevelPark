# Week 12 procedure — final allocation analytics

1. Store three invented allocations in an `ArrayList`.
2. Group their grid labels with a stream.
3. Derive the fixed free-cell count from six total cells.
4. Print the final simulator report.

Compile and run with `javac ParkingWeek12.java` followed by `java ParkingWeek12`.

> This is a fictional classroom slot-allocation simulator. It has no real vehicles, licence plates, people, locations, payments, personal data, or live parking function.
