# Week 8 procedure — recursive cell inspection

1. Store six fixed occupied/free flags.
2. Recursively count all inspected cells.
3. Recursively count free flags.
4. Derive occupied count from total minus free.

Compile and run with `javac ParkingWeek08.java` followed by `java ParkingWeek08`.

> This is a fictional classroom slot-allocation simulator. It has no real vehicles, licence plates, people, locations, payments, personal data, or live parking function.
