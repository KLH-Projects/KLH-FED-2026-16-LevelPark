# Week 7 procedure — allocation edge cases

1. Begin with one fixed fictional allocation.
2. Try to add a duplicate invented token.
3. Try to add a cell outside the fixed GRID-A range.
4. Confirm the state is unchanged.

Compile and run with `javac ParkingWeek07.java` followed by `java ParkingWeek07`.

> This is a fictional classroom slot-allocation simulator. It has no real vehicles, licence plates, people, locations, payments, personal data, or live parking function.
